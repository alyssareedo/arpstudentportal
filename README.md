# Fluent Path

Create a modern ESL student management web application for English teachers and language schools. The platform should have a clean, professional, mobile-responsive UI using blue and white colors with modern cards, charts, rounded corners, subtle shadows, and intuitive navigation.

Core Features:

1. Dashboard
- Display total students count
- Upcoming lessons widget
- Attendance charts and analytics
- Monthly student progress charts
- Quick actions for adding students and lessons
- Responsive dashboard cards

2. Student CRM
Each student profile should include:
- Student profile page with avatar, contact info, level, goals
- Lesson history timeline
- Homework tracking
- File uploads for PDFs and assignments
- Attendance records
- Speaking score tracking
- Grammar score tracking
- Teacher notes section
- Progress overview charts
- Shareable student page links

3. Lesson Management
Each lesson entry should include:
- Lesson date and time
- Lesson topic
- Zoom meeting link field
- Microsoft Teams meeting link field
- Homework assignment section
- Teacher notes
- Attendance status
- Lesson completion tracking

4. Monthly Reports
Generate detailed monthly reports with:
- Attendance percentage
- Progress charts
- Teacher comments
- Lessons completed
- Student performance summaries
- Export-friendly report layout

5. Admin Features
- Add/edit/delete students
- Upload PDFs and study materials
- Share student pages securely
- Mobile responsive design
- Search and filter students
- Authentication-ready admin layout

Technical and UI Requirements:
- Modern React frontend
- Use reusable components
- Dashboard analytics charts
- Sidebar navigation
- Mobile-first responsive design
- Blue and white color palette
- Elegant typography and spacing
- Smooth transitions and hover states
- Clean database-ready structure
- Sample mock data included

Pages to include:
- Login page
- Dashboard
- Students list
- Student detail page
- Lessons page
- Reports page
- Settings page

Include realistic sample data and polished UI design inspired by modern SaaS dashboards.
